# Risdel Bookshops v0.36.2 — Figma Dashboard Fidelity Refresh

This cumulative UI release refines the existing v0.36.1 application shell and executive dashboard to closely match the approved Figma-style reference while preserving all existing modules, Google Sheets data, routes, RBAC and business logic.

## Highlights
- Refined 215px domain navigation with live approval/notification badges.
- Figma-style open-book brand mark and "Books Build People" sidebar footer.
- Compact global search/topbar, branch selector and administrator profile treatment.
- Refined executive hero, four KPI cards, sales/gross-profit chart and live end-point tooltip.
- Management Attention panel driven by low stock, pending approvals, overdue receivables, supplier delays and system alerts.
- Permission-aware six-tile Quick Actions panel.
- 30-day Sales Channels donut, Inventory Health and Financial Position cards.
- Top Selling Products now includes category data from the catalogue product record.
- Recent Business Activity now includes a reference column.
- Dashboard data fallbacks calculate live sales today, transactions today and monthly gross profit from completed POS sales when dashboard metrics have not yet been published.
- Dashboard now calculates pending approvals, overdue receivables, supplier delivery delays and current-month operating expenses.
- Responsive desktop/tablet/mobile styling retained.

No Google Sheets schema migration is required for this visual release.
