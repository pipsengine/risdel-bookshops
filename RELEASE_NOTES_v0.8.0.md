# Risdel Books v0.8.0 — Module 07 Point of Sale

Module 07 is a cumulative update of v0.7.0.

## Added
- Barcode / ISBN / product search POS register
- Cashier shift opening and closing
- Walk-in and saved customer selection
- Controlled line discounts with override permission
- Cash, Card/POS and Bank Transfer payment methods
- Split payments and cash change calculation
- Held sales
- Sales transaction register
- Printable receipt view
- Automatic stock deduction and inventory movement entries
- Sales audit trail
- Executive dashboard sales KPI publication
- Google Sheets schema GS-005

## Google Sheets added
- CRM_Customers
- System_PaymentMethods
- Sales_CashierShifts
- Sales_Transactions
- Sales_TransactionLines
- Sales_Payments
- Sales_HeldSales
- Sales_HeldSaleLines

Run `npm run sheets:init` after upgrading.
