# Risdel Books v0.21.0 — Module 20
## General Ledger & Automated Accounting Posting

Adds an idempotent double-entry posting engine, posting center, manual journals, general ledger inquiry, trial balance, source-document traceability, posting runs, posting rules and Google Sheets schema GS-018.

Automated sources currently include POS sales, sales invoices, customer receipts, approved supplier invoices, supplier payments and processed customer refunds.
